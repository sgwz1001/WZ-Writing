# 文载 Writing

> 面向中文写作者的**本地优先**写作工作台。稿件全程留在你自己的硬盘上，断点续写、崩溃可恢复。
> 界面采用米哈游系（原神 / 崩坏：星穹铁道 / 绝区零）风格的 HUD 框架语言，专注、克制的科幻感。

---

## 这是什么

文载 Writing 是一个用 **Tauri 2 + Vue 3 + Rust** 打造的桌面写作软件，目标是：

- **本地优先**：所有稿件、词库、设置都存在本机，不强制联网、不上传内容。
- **边写边纠错**：内置纯本地纠错引擎，把错别字、标点全/半角、重复标点等问题实时用波浪线标出来，对照面板里一键「应用 / 应用全部 / 忽略」。
- **可自定义**：自带高频错词种子库，可一键载入、增删，也可维护「白名单」保护专有名词不被误改。
- **AI 就绪**：内置多厂商大模型接入层（设置里填 Key / 选模型 / 填端点即可），为后续「大模型深度纠错」打底。

## 安装

1. 到 [Releases](../../releases) 页面下载 **`文载 Writing_x.x.x_x64-setup.exe`**。
2. 双击安装（首次安装若提示缺少 WebView2，按引导在线安装即可，仅需一次）。
3. 开始写作。

> 当前为未签名构建，Windows SmartScreen 可能给出安全提醒，选择「仍要运行」即可。

## 使用速览

- **启动**：首次运行进入「身份」页择道；老用户直接进入「首页」总览，可看到最近项目与常用身份的 🔥。
- **换身份**：工作室左上角「⌂ 首页」回总览、「⇄ 换身份」重新择道；各身份的项目相互独立。
- **写**：首页点「继续写」直达上次的章节；工作室左侧是卷 → 章目录树，可拖拽排序、双击改名。
- **新建项目**：在工作室点「+ 新建项目」会弹窗提示输入项目名 / 书名，并按身份自动生成初始章节。
- **新建章节**：默认按已有章节数推荐「第 N 章」（已有第一章则顺延第二章），可直接回车采用，也可自己改。
- **纠错**：写作时问题处会出现波浪线；右侧「纠错」面板列出全部问题，可逐条或批量处理。
- **词库**：点工具栏「词库」打开管理面板，点「载入内置词库」即可获得高频错词；也可手动添加或批量导入。专有名词加到「白名单」避免被误改。
- **诗词**：打开「诗词」面板，近体诗选体裁校验；词牌页可搜索 103 个词牌、选牌自动铺空行、逐句校验；乐府 / 散曲 / 文言 / 赋有模板引导；「AI 创作」输入主题即可生成并插入正文。
- **取标题**：选中文本 →「取标题」，可选网文 / 文艺 / 悬疑 / 纪实 / 外国文学（英文 + 中文释义）风格。
- **皮肤**：设置 →「外观」切换原神 / 星铁 / 绝区零，可上传自定义背景图并调节浓度。
- **设置**：任意界面右下角的**齿轮按钮**都能打开设置，内含皮肤切换、日夜模式、毛玻璃强度、动画总开关、AI 接入与版本信息。
- **AI**：设置 →「AI 接入」填写厂商、API Key、模型，「测试连接」通过后即可在 AI 功能中使用。Key 仅存储在本机。
- **关动画**：设置 →「动效」关掉「启用界面动画」，全局动效即刻停用，重启后依然保持。

## 技术栈

- 前端：Vue 3 + TypeScript + Vite + Tauri Vue 绑定 + Tiptap
- 后端：Rust + Tauri 2 + rusqlite（SQLite，源码内联打包，无需预装）
- 打包：NSIS（Windows 安装包）

## 隐私与安全

- 稿件、词库、设置 **全部存于本机**（`文档/文载` 目录下的本地数据库）。
- 大模型 API Key 仅保存在本机设置中，不会上传到任何第三方服务器（除你选用的模型厂商 API 调用本身）。
- 本地纠错引擎 **完全离线**，不联网。
